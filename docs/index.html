Add a lesson

Lessons are made from slides by Claude. Anyone can suggest one; the site's owner checks it before it goes live for everyone.

  1. Make your own copy (once only)

    Sign in to GitHub, open github.com/nbastudyhub/nba and press Fork, then Create fork. You only do this the first time.

  2. Open Claude Code on your copy

    Go to claude.ai/code and start a new session with your-github-name/nba selected. If it isn't listed, connect GitHub to Claude when it asks.

  3. Attach your slides and send this message

    Add the PowerPoint (.pptx) or PDF, then send:

    Add this lesson to the Study Hub, then open a pull request to nbastudyhub/nba so the owner can approve it.

  4. Send it for approval

    If Claude couldn't open the pull request itself, go to your copy on GitHub, press Contribute, then Open pull request, then Create pull request.

  5. Wait for the owner

    The owner gets a notification, checks your lesson and presses Merge. About a minute later it appears here for everyone.

  4. Approving a friend's lesson

    On github.com/nbastudyhub/nba/pulls, open their pull request and check Files changed: it should only add files in docs/decks/. If it changes anything else, ask why before merging. Happy? Press Merge pull request, then Confirm merge.

Tips: One lesson per file works best. Keep the speaker notes in: that's often where the answers are. An old .ppt file needs saving as .pptx or PDF first. If a slide is mostly a picture, tell Claude what it shows. No GitHub account? Send your slides to the site's owner instead.
