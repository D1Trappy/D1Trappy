Add a lesson

New lessons are made from your slides by Claude, then published here for everyone. It takes about five minutes from upload to live.

  1. Open Claude Code

    Go to claude.ai/code and start a new session with the repository nbastudyhub/D1Trappy selected.

  2. Attach your slides

    Add the PowerPoint (.pptx) or PDF. One lesson per file works best. Keep the speaker notes in: that's often where the answers are.

  3. Send this message

    Add this lesson to the Study Hub and publish it.

  4. Refresh this page

    When Claude says it's published, wait about a minute and refresh. The new lesson appears in the topic list at the top.

Tips: An old .ppt file needs saving as .pptx or PDF first. If a slide is mostly a picture, tell Claude what it shows. Using someone else's Study Hub? Send your slides to its owner and they can add them.
